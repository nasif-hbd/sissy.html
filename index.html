Installing on another device

iPhone or iPad

  1. Open this page in Safari
  2. Tap Share (the square with an arrow)
  3. Tap “Add to Home Screen”

Android

  1. Open this page in Chrome
  2. Tap the ⋮ menu
  3. Tap “Install app”

Windows, Mac, Linux, ChromeOS

  1. Open this page in Chrome or Edge
  2. Click the install icon in the address bar, or ⋮ → “Install VocabX”

Windows, without a browser install

  1. Download the Windows version
  2. Unzip it anywhere
  3. Double-click VocabX.exe

The Windows download is not code-signed, so SmartScreen warns the first time: click “More info” → “Run anyway”. If you would rather not, the browser install above gives you the same app, window and offline support.
