Installing on another device

iPhone or iPad

  1. Open this page in Safari
  2. Tap Share (the square with an arrow)
  3. Tap “Add to Home Screen”

Android

  1. Open this page in Chrome
  2. Tap the ⋮ menu
  3. Tap “Install app”

Download it instead — Windows, Mac or Linux

  1. Windows — unzip, run VocabX.exe
  2. Mac — unzip, drag VocabX to Applications
  3. Linux — unzip, run ./VocabX

No installer and no runtime: each one is a launcher and the app in a folder, and it serves itself on 127.0.0.1 with nothing exposed to your network. None of them is signed, so the first run needs one extra click — “More info → Run anyway” on Windows, right-click → Open on a Mac. The README inside each says so too.

Chromebook, or any of the above from the browser

  1. Open this page in Chrome or Edge
  2. Click the install icon in the address bar, or ⋮ → “Install VocabX”
